# Brat Album Cover Style Tips

Album-cover style graphics are simple to make: flat colour, plain text and lots of space. If you want a quick starting point, a [brat generator](https://bratgeneratortool.com/) can produce a clean text cover from your own words in a few clicks. These tips cover the design basics.

## Start with one flat colour

Pick a single bold background colour. Flat colour keeps the cover clear even when it is shown as a tiny thumbnail on a phone.

## Keep the text plain

Use lowercase text in a simple sans-serif font. Short titles work best, and one or two lines are usually enough.

## Mind the spacing

Leave generous margins. Place the text in the centre or the top left, and avoid crowding the edges.

## Export at a square size

Square images suit playlist covers, profile pictures and music posts. Check the result at small size before you publish it.
